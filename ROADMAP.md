# Romi — Product Roadmap & Launch Plan

**Last updated:** August 28, 2026
**Status:** Planning → Foundation

## Vision

Romi is a mobile-first road-life companion for nomads, RVers, campers, and remote workers.
It helps people find sleep, water, bathrooms, food/fuel, laundry, dog needs, and reliable connectivity using real place data and honest traveler reports.

The premium feature is an AI companion ("Roamy") that you can talk to. It understands your vehicle, preferences, and current situation, then builds practical day-by-day road plans.

## Core Free Features (V1)

- Search real places for sleep, water, bathrooms, food/fuel, laundry, dogs, connectivity
- Place detail pages
- Save places to a private account
- Create and manage multiple road plans
- Submit Scout reports + photos
- Admin review before community reports go public
- Simple Today dashboard

**First working test:**
Search a real place → save it → create a plan → add the place → refresh → it stays saved.

## What Makes Romi Awesome

1. Offline-first
2. Vehicle- and lifestyle-aware
3. Freshness and trust signals on reports
4. Proactive suggestions, not just search
5. Dead-simple Today view
6. AI companion that feels like a real co-pilot

## Three-Month Launch Plan

### Month 1 — Core Foundation
- App screens: Today, Search, Saved, Plans
- First real places (starting with confirmed Paonia stops)
- Place detail pages
- Save a place
- Create a basic road plan
- Mobile-first UI

**Success:** search → save → add to a plan → refresh → it sticks.

### Month 2 — Useful Features
- Multiple road plans
- Scout reports + photos + admin review
- Today dashboard
- Basic offline support
- Vehicle profile

### Month 3 — Polish, AI Premium & Soft Launch
- Harden UI, analytics, privacy policy, terms
- Deploy
- Soft launch to nomads / RVers
- Start the AI companion

## Monetization

Free: search, save, basic plans, Scout reports, Today dashboard.
Premium: AI companion — about $8–12 / month.

## Highest-Leverage Build Order

1. Search + save + basic road plans
2. Make the AI planner actually good
3. Trust/freshness signals
4. Nail the Today dashboard
