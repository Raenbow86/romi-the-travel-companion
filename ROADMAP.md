# ROMI roadmap

Snapshot: September 9, 2026. The live app is ahead of the old revert note that used to sit here.

## Now — accuracy

Do not add features until this is true:

One shared filtered-results engine powers the list, the cards, and the pins.

Define each chip in plain English before touching code. Examples:

- **Dog Needs → Vet** = veterinary clinics and emergency vets. Not dog parks. Not pet stores.
- **Dog park** = dog parks.
- **Fuel + Food** = places that actually do both (The Powerstop is the gold example).
- **Shower** = a place a traveler can shower. Not Valley Glass.

Test the same 5–6 searches in:

1. Salida (81201)
2. Gunnison
3. Paonia
4. A ZIP code
5. Use my location

If it behaves in all five, we are building something real.
